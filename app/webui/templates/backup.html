Gateway aktualisieren

Lädt die aktuelle Version aus dem Git-Repository und baut den Container neu. Voraussetzung: der Host-Watcher-Service (exo-gateway-updater.service) muss auf der Azure-VM laufen (Einrichtung → Update-Watcher). Im Kanal "Releases" kann gezielt eine bestimmte Version gewählt werden — auch ein Rollback auf eine ältere Version ist damit möglich (Code-Stand; Einstellungen bleiben unverändert).

⚠ Rollback auf ältere Version — Einstellungen (settings.json) werden nicht automatisch zurückgesetzt.

    Erstellt ein vollständiges ZIP-Archiv aller kritischen Gateway-Daten — geeignet
    für Migrationen, Umzüge auf neue Server oder als regelmäßige Sicherungskopie.

    Leichtgewichtiger Export nur der Einstellungen (XML) — im Unterschied zum vollständigen
    Backup oben ohne Zertifikate/Keys/Logs. Passwörter und Secrets werden nicht
    exportiert und müssen nach einem Import manuell ergänzt werden.
